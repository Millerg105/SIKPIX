# SikPix — Custom Car Art by Big Mon

Custom car artwork e-commerce site. Upload your car, choose a style, get a one-of-one digital poster or printed canvas.

## Tech Stack

- **Frontend**: Vite + React + TypeScript + Tailwind CSS + shadcn-ui
- **Backend**: Supabase (Edge Functions, Storage)
- **Commerce**: Shopify (Draft Orders via Admin API, Storefront API)
- **Print on Demand**: Gelato

## Development

```sh
npm install
npm run dev
```

## Deployment

Deployed to Vercel. Push to `main` to trigger auto-deploy.

- **Live**: [sikpix.co.uk](https://sikpix.co.uk)
